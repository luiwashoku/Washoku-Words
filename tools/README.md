# Voice comparison tools

These retained comparison pages are separate from the main app. Both use a root-relative document base so their recordings and app links resolve correctly from this folder.

- `tts-quality-check.html`: historical voice comparison and browser speech checks.
- `tts-sample.html`: original Nova/Shimmer experiment, regenerated by `scripts/generate-tts-sample.py`. Some historical sample recordings were already absent before the reorganization.

These are reference tools, not the current default recording workflow. See `AGENTS.md` for current Marin preferences.
